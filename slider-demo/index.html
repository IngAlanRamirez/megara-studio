Cómo usar el Slider

El componente ImageSlider acepta las siguientes props:

  • images: Array de objetos con src, alt y title opcional
  • autoplay: Boolean para activar/desactivar reproducción automática (default: true)
  • autoplaySpeed: Velocidad en milisegundos entre transiciones (default: 5000)
  • showDots: Boolean para mostrar/ocultar indicadores de puntos (default: true)
  • showArrows: Boolean para mostrar/ocultar flechas de navegación (default: true)

Ejemplo de uso:

<ImageSlider 
  images=[object Object][object Object][object Object][object Object][object Object][object Object][object Object][object Object]
  autoplay=true
  autoplaySpeed=4000
  showDots=true
  showArrows=true
/>
